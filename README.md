# 🎮 Meu Jogo de Navegador (Top-Down Shooter)

Bem-vindo(a) ao meu minijogo de navegador! 

Este é um projeto muito simples e direto ao ponto: **um joguinho (estilo top-down shooter) feito inteiramente em um único arquivo HTML**. A ideia era ver até onde eu conseguia ir criando toda a lógica, a interface e a renderização sem quebrar o código em vários arquivos separados. E aqui está o resultado!

## 🚀 Como jogar
Não precisa instalar nada, nem rodar servidor local, nem usar terminal. Só precisa de duas coisas:
1. Baixar este repositório (ou clonar).
2. Dar um duplo clique no arquivo `DEMO.html` e ele vai abrir direto no seu navegador. Divirta-se!

## 🛠️ O que tem aí dentro?
Todo o código (HTML, CSS e a lógica em JavaScript) está enfiado dentro do `DEMO.html`. O projeto também conta com:
* **`audio/`**: Contém a trilha sonora (`musica.mp3`) para dar aquele clima.
* **`Sprites/`**: A pasta com todos os gráficos 2D do jogo. Tem de tudo um pouco: o jogador, projéteis, mira, cenários (grama, pedras, árvores) e os inimigos (boss, grunt, runner, tank), além da estrela e do coração de vida.

## 📝 Nota do desenvolvedor
Colocar todo o código em um único arquivo HTML é uma bela bagunça se o projeto for ficar grande, mas foi um ótimo exercício para entender como as coisas funcionam por baixo dos panos! 

Sinta-se livre para abrir o `DEMO.html` no seu editor de código favorito e fuçar no que quiser. 🕹️
